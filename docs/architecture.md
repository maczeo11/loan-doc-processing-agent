# FinScan AI Architecture & Component Boundaries

FinScan AI is a GenAI-assisted loan document verification and underwriting agent designed for bank underwriters.

## Architectural Principles

1. **Deterministic code decides. AI explains. A human approves.**
   - No financial arithmetic or pass/flag decision is generated by an LLM.
   - LLMs are used solely to explain, summarize, and retrieve contextual policy knowledge.

2. **Every fact carries evidence.**
   - Extracted facts require an `EvidenceRef` with page number and bounding-box coordinates.
   - Missing or unverifiable facts return `UNKNOWN`, never a guess.

3. **Ports and Adapters:**
   - Storage: Local Filesystem (dev) / S3 (cloud)
   - Queue: PostgreSQL `FOR UPDATE SKIP LOCKED` (dev) / SQS (cloud)
   - LLM: OpenCode Zen / Qwen3-4B-Instruct GGUF (offline)

## Data Flow & State Transitions

### Application Lifecycle States

```
UPLOADED → QUEUED → PROCESSING → READY_FOR_REVIEW → REVIEWED
                                        ↓
                                 NEEDS_INFORMATION
                                        ↓
                                    CANCELLED
                                        
PROCESSING → FAILED (on error)
```

### LangGraph Node Sequence

| Node | Input | Output | Purpose |
|------|-------|--------|---------|
| `triage_node` | `document_ids`, `document_manifest` | Status: PROCESSING/FAILED | Validates dossier manifest |
| `ocr_and_classify_node` | PDF binaries | `classified_types` | Routes OCR, classifies pages |
| `extract_facts_node` | Classified pages | `PayslipFacts`, `BankStatementFacts`, etc. | Extracts structured facts with EvidenceRef |
| `evaluate_rules_node` | Extracted facts | `Finding[]` | Deterministic rule execution |
| `retrieve_policy_node` | Flagged findings | `retrieved_chunk_ids` | Hybrid RAG retrieval |
| `synthesize_summary_node` | Findings + chunks | `summary_markdown` | Credit Appraisal Memo |
| `validate_grounding_node` | Summary + citations | `summary_grounded: bool` | Citation validation gate |
| `human_review_node` | Reviewer decision | Final status | Human-in-the-loop checkpoint |

## Queue Architecture

### PostgreSQL `SKIP LOCKED` (Local Development)

```sql
-- Atomic lease claim
WITH claimed AS (
    SELECT id, job_id, payload
    FROM outbox_jobs
    WHERE status IN ('PENDING', 'DISPATCHED')
      AND (locked_until IS NULL OR locked_until < clock_timestamp())
    ORDER BY created_at ASC
    LIMIT 1
    FOR UPDATE SKIP LOCKED
)
UPDATE outbox_jobs t
SET status = 'PROCESSING',
    locked_until = clock_timestamp() + interval '30 seconds'
FROM claimed
WHERE t.id = claimed.id
RETURNING t.job_id, t.payload;
```

### AWS SQS + DLQ (Cloud Deployment)

- **Primary Queue**: Receives `JobRef` messages from API outbox dispatcher
- **Visibility Timeout**: 30 seconds (extended by LeaseHeartbeat)
- **Dead Letter Queue**: Receives messages after 3 failed delivery attempts
- **Message Attributes**: `job_id`, `application_id`, `priority`

## Storage Architecture

### Canonical Key Hierarchy

```
dossiers/{application_id}/{document_id}_{sanitized_filename}
```

**Examples:**
- `dossiers/APP-25195/doc-payslip-aug_payslip_august.pdf`
- `dossiers/APP-25195/doc-bank-stmt_bank_statement_q3.pdf`
- `dossiers/APP-25195/doc-pan-card_pan_scan.pdf`

### Security Model

| Layer | Enforcement |
|-------|-------------|
| **Server-Side Encryption** | `AES256` mandatory on all S3 uploads |
| **Tenant Isolation** | `validate_storage_key()` enforces `dossiers/{application_id}/` prefix |
| **Path Traversal Prevention** | `sanitize_filename()` strips `../`, `..\\`, special chars |
| **Presigned URLs** | TTL clamped to 5-60 minutes, cryptographically signed |
| **Integrity Verification** | SHA-256 checksum validated on upload completion |

## Technology Stack Summary

| Layer | Technology | Rationale |
|-------|------------|-----------|
| **API Framework** | FastAPI + Pydantic v2 | Strict schema validation, async I/O, OpenAPI generation |
| **Orchestration** | LangGraph + SQLite checkpointer | Stateful graph, transactional resume, interrupt checkpoints |
| **Frontend** | React 18 + Vite + TypeScript + Tailwind | Fast static build, type safety, utility-first styling |
| **Document Viewer** | pdf.js | Direct canvas rendering, bounding-box overlays |
| **Database** | PostgreSQL 16 | Authoritative persistence, SKIP LOCKED, outbox pattern |
| **Cache** | Redis 7 | Rate limiting, token buckets, session state |
| **Queue** | PG SKIP LOCKED / AWS SQS | Pluggable behind QueuePort, atomic leases |
| **Storage** | Local FS / AWS S3 | Pluggable behind StoragePort, presigned URLs |
| **OCR** | PyMuPDF → PaddleOCR → AWS Textract | Routing based on page text properties |
| **RAG** | BM25 + BGE-small-en-v1.5 + FAISS | Hybrid lexical+dense, RRF fusion |
| **LLM** | OpenCode Zen / Qwen3-4B GGUF | Structured output, prompt injection isolation |
| **Classifier** | TF-IDF + LogisticRegression | CPU-friendly, 0.91+ Macro-F1, <50MB RAM |
